# Community Notice Translation Tool

A simple website for creating, browsing, and searching community notices in English, Punjabi, Hindi, and Urdu.

## Run the project

Open `index.html` in a web browser. No installation is required.

## Pages

- `index.html` — browse notices, filter by category, and use the admin form to add notices.
- `about.html` — learn about the project.

The site uses HTML, CSS, and JavaScript. New notices are only kept in the current page session; they are not saved to a database.
