About Us

Community Notice Translation Tool

The problem

Multilingual communities may miss important notices when information is published in only one language.

Our goal

Create a platform for publishing community notices in multiple languages, so everyone can read them in the language they understand.

What our tool can do

  • Notice creation: the Admin writes a new notice.
  • Language versions: each notice can be read in English, Punjabi, Hindi or Urdu.
  • Translation status: tags show if each language is Translated or Pending, and a dictionary translator can fill in the translations.
  • Categories: Health, Education, Safety and Events.
  • Publish and expiry: visitors only see notices that are live today.
  • Search: type a word to find a notice.
  • Accessibility: skip link, labels on every field, keyboard outline and screen reader messages.
  • Admin roles: only the Admin can create notices and see expired ones.

How we built it

  • HTML: the structure of the pages.
  • CSS: the colours, layout and background image.
  • JavaScript: shows, hides, searches and adds notices.
